表11.C 递归自由原则速查卡
| 项目 | 内容 |
|------|------|
| 原则编号 | RFP |
| 原则名称 | 递归自由原则 |
| 英文名称 | Recursive Freedom Principle |
| 核心表述 | 行动应当保持或扩展可能性空间，而非不可逆地压缩它 |
| 形式化 | $\forall a: \text{RFD}(a) \geq \theta_{\min} \vee \text{SpecialJustification}(a)$ |
| 默认阈值 | $\theta_{\min} = 0$ |
| RFD定义 | $\text{RFD}(a) = \frac{M(PS(s_1, T)) - M(PS(s_0, T))}{M(PS(s_0, T))}$ |
| 递归条款 | $\text{Apply}(RFP) \rightarrow \neg\text{Close}(\text{Revise}(RFP))$ |
| 例外条件 | 必要性 + 比例性 + 最小化 |
| 理论锚定 | NC-1（关系性）、NC-（参与性）、BP-（主体间性） |
| 操作化指标 | RFD（递归自由度） |
| 适用边界 | 主体边界、行动边界、情境边界、时间边界 |
| 例外情况 | 紧急避险、帕累托改进、协商同意 |

| 操作化指标 | CRV（承诺-验证比）、CSIA的D₄维度 |
| 适用边界 | 深不确定性情境、影响较大的决策、长期影响的决策 |
| 例外情况 | 紧急情况、不可避免的不可逆性、协商同意、更高原则 |
