[B] 一、本附录的任务与定位
本附录为《星际文明的规范性重构》提供最小论证路径（Minimal Argument Path, MAP）。全书的论证体系庞大而复杂，涉及多个学科领域和多层次的理论建构。最小论证路径旨在提炼出从核心问题到制度设计的最简洁、最关键的推理链条，使读者能够快速把握全书的核心逻辑，同时为批判性检验提供明确的焦点。

[B] 二、最小论证路径的性质

[B] 定义J.0.1（最小论证路径）
$$\text{MAP} \triangleq \min_{\text{Path}} |\text{Path}| \text{ s.t. } \text{Path} \vdash \text{Conclusions}$$
最小论证路径是能够推导出核心结论的最短有效推理链条。

[B] 规则J.0.1（MAP的性质）

[B] | 性质 | 描述 |
|------|------|
| 必要性 | 路径中每一步都是必要的 |
| 充分性 | 路径足以推导核心结论 |
| 简洁性 | 删除任一步骤将导致推理失效 |
| 可检验性 | 每一步都可独立检验 |

[B] J.1.2.2 最小论证路径作为检验焦点

[B] 规则J.1.4（焦点功能）

2. 标识关键推理：突出哪些推理步骤是核心
3. 定位脆弱点：指出论证中最可能被挑战的环节
4. 建议检验策略：为每个关键节点提供检验建议
形式化表述
$$\text{CriticalFocus} = \{(\text{Node}_i, \text{Vulnerability}_i, \text{TestStrategy}_i)\}$$

[B] J.2.1.1 问题的形式化陈述

[B] 定义J.2.1（核心问题）
$$\text{CoreProblem} \triangleq \text{How to establish normative framework for } \mathcal{S}_{interstellar}?$$
其中$\mathcal{S}_{interstellar}$是星际文明情境的集合，包括：
$$\mathcal{S}_{interstellar} = \{\text{AGI}, \text{ASI}, \text{SpaceColonization}, \text{FirstContact}, \text{PostHuman}, ...\}$$

[B] J.2.1.2 问题的三个维度

[B] 规则J.2.1（问题的三个维度）

[B] | 维度 | 问题 | 形式化 |
|------|------|--------|
| 规范性根基 | 规范性从何而来？ | $\text{Source}(\text{Normativity}) = ?$ |
| 深不确定性 | 在深不确定性下如何决策？ | $\text{Decision}(\text{DeepUncertainty}) = ?$ |
| 长程责任 | 如何归因长程责任？ | $\text{Attribution}(\text{LongTermResponsibility}) = ?$ |

[B] 谜题一：规范性的宇宙根基
$$\text{Puzzle}_1: \text{What grounds normativity in a cosmos without pre-given purposes?}$$
核心张力：
- 自然主义：宇宙是无目的的物理过程
- 规范性需求：我们需要"应该"的指引
- 问题：如何从"是"过渡到"应该"？

[B] 谜题二：深不确定性下的理性
$$\text{Puzzle}_2: \text{How to be rational under deep uncertainty?}$$
核心张力：
- 标准决策理论依赖概率
- 星际文明情境面临深不确定性
- 问题：没有可靠概率时如何决策？

[B] 谜题三：长程责任的归因
$$\text{Puzzle}_3: \text{How to attribute responsibility across deep time?}$$
核心张力：
- 传统责任归因依赖近因
- 星际文明决策影响深远
- 问题：如何对长程后果负责？

[B] J.2.1.3 问题的紧迫性

[B] 规则J.2.2（问题的紧迫性论证）

[B] J.2.4.1 新宇宙观（NC）

[B] 定义J.2.2（新宇宙观核心命题）

[B] | 命题 | 陈述 | 形式化 |
|------|------|--------|
| NC-1 | 关系先于实体 | $\text{Relation} \prec \text{Entity}$ |
| NC-2 | 过程先于状态 | $\text{Process} \prec \text{State}$ |
| NC-3 | 参与先于旁观 | $\text{Participation} \prec \text{Observation}$ |

[B] NC-1的含义
$$\text{NC-1}: \forall e.\text{Entity}(e) \Rightarrow \exists R.\text{ConstitutedBy}(e, R)$$
实体由关系网络构成，而非独立存在。

[B] NC-2的含义
$$\text{NC-2}: \forall s.\text{State}(s) \Rightarrow \exists p.\text{MomentOf}(s, p)$$
状态是过程的切片，而非过程的基础。

[B] NC-3的含义
$$\text{NC-3}: \forall k.\text{Knowledge}(k) \Rightarrow \exists a.\text{InvolvedIn}(a, k)$$
知识涉及主体的参与，而非被动观察。

[B] J.2.4.2 新生命观（NL）

[B] 定义J.2.3（新生命观核心命题）

[B] | 命题 | 陈述 | 形式化 |
|------|------|--------|
| NL-1 | 生命是跨基质的 | $\text{Life} \not\Rightarrow \text{CarbonBased}$ |
| NL-2 | 生命的本质是负熵组织 | $\text{Life} \equiv \text{NegentropyOrganization}$ |
| NL-3 | 主体资格是连续谱 | $\text{Agenthood}: \mathcal{E} \rightarrow [0, 1]$ |

[B] NL-1的含义
$$\text{NL-1}: \Diamond\exists x.[\text{Life}(x) \land \neg\text{CarbonBased}(x)]$$
生命可能存在于非碳基基质上（如硅基AI或其他形式）。

[B] NL-2的含义
$$\text{NL-2}: \text{Life}(x) \Leftrightarrow \text{SelfMaintaining}(\text{NegentropyOrganization}(x))$$
生命的本质是自我维持的负熵组织。

[B] NL-3的含义
$$\text{NL-3}: \text{Agenthood}: \mathcal{E} \rightarrow [0, 1]$$
主体资格不是二元的，而是程度性的连续谱。

[B] J.2.4.3 新认知观（NK）

[B] 定义J.2.4（新认知观核心命题）

[B] | 命题 | 陈述 | 形式化 |
|------|------|--------|
| NK-1 | 认知是参与式的 | $\text{Cognition} \equiv \text{Participation}$ |
| NK-2 | 知识是社会建构的 | $\text{Knowledge} \equiv \text{SocialConstruction}$ |
| NK-3 | 存在深不确定性 | $\exists \phi.\text{DeepUncertainty}(\phi)$ |

[B] 规则J.3.1（是-应当问题的处理）
本著作的策略：不是直接从"是"推导"应当"，而是识别规范性得以可能的存续条件。
$$\text{Strategy}: \text{Is} \xrightarrow{\text{SurvivalConditions}} \text{Ought}$$

[B] J.3.1.2 桥梁原则

[B] 定义J.3.1（桥梁原则）

| BP-2 | 存续依赖条件 | $\text{Survival} \Rightarrow \text{Conditions}$ |
| BP-3 | 维护条件是理性的 | $\text{Rational} \Rightarrow \text{Maintain}(\text{Conditions})$ |

[B] BP-1的论证

要有规范性，首先要存在能够承载规范的主体。

[B] BP-2的论证
$$\text{BP-2}: \text{Exists}(x) \Rightarrow \text{SurvivalConditions}(x)$$
存续依赖于特定条件的满足。

[B] BP-3的论证
$$\text{BP-3}: \text{Rational}(a) \land \text{Wants}(\text{Normativity}) \Rightarrow \text{Maintain}(\text{SurvivalConditions})$$
理性主体若想保持规范性思考的可能，就应该维护其存续条件。

[B] J.3.1.3 桥梁原则的整合

[B] 定理J.3.1（桥梁论证）
$$\text{BP-1} \land \text{BP-2} \land \text{BP-3} \vdash \text{Normativity} \Rightarrow \text{Maintain}(\text{SurvivalConditions})$$
证明（概要）：
1. 规范性预设存续（BP-1）
2. 存续依赖条件（BP-2）
3. 理性要求维护条件（BP-3）
4. 因此，规范性要求维护存续条件 $\square$

[B] D.1.1.1 协议栈的定义

[B] 定义D.1.1（协议栈）
$$\text{ProtocolStack} \triangleq \langle L_0, L_1, L_2, L_3, L_4, \text{OneLoop} \rangle$$
其中：
- $L_0$：物理约束层（Physical Constraints Layer）
- $L_1$：本体-认识论框架层（Ontological-Epistemological Framework Layer）
- $L_2$：规范原则层（Normative Principles Layer）
- $L_3$：制度设计层（Institutional Design Layer）
- $L_4$：操作协议层（Operational Protocols Layer）
- $\text{OneLoop}$：版本化回滚环（Versioned Rollback Loop）

[B] D.1.1.2 协议栈的目的

[B] 规则D.1.1（目的声明）

[B] 协议栈的目的是为星际文明治理提供一个模块化、可追溯、可修订的规范性框架。
形式化表述
$$\text{Purpose}(\text{ProtocolStack}) = \text{Modularity} \land \text{Traceability} \land \text{Revisability}$$

[B] 目的分解

[B] | 目的 | 定义 | 实现方式 |
|------|------|----------|
| 模块化 | 各层级可独立设计和修订 | 层级分离，接口明确 |
| 可追溯 | 每条规则可追溯到上层约束 | 承重关系，依赖标注 |
| 可修订 | 规则可根据反馈进行修订 | 版本化管理，回滚机制 |

[B] 概述

[B] D.2.1 热力学约束规则
_______________________________________________________________________________

[B] D.2.1.1 热力学第一定律约束

[B] 规则D.2.1（能量守恒约束）
任何治理方案不得假设违反能量守恒定律。
形式化表述
$$\forall \text{Action } a: \Delta E_{\text{system}} + \Delta E_{\text{environment}} = 0$$

[B] 应用含义

[B] | 含义 | 描述 |
|------|------|
| 资源有限性 | 可用能量资源有限，需要分配 |
| 能量成本 | 任何行动都有能量成本 |
| 转换效率 | 能量转换存在效率约束 |

[B] D.2.1.2 热力学第二定律约束

[B] 规则D.2.2（熵增约束）
任何治理方案不得假设违反熵增定律。
形式化表述
$$\forall \text{Process } p: \Delta S_{\text{total}} \geq 0$$

[B] 应用含义

[B] | 含义 | 描述 |
|------|------|
| 不可逆性 | 某些过程在热力学上不可逆 |
| 负熵成本 | 维持有序结构需要负熵输入 |
| 耗散必然 | 复杂系统必然耗散能量 |

[B] 规则D.2.3（负熵依赖）
复杂系统（包括生命和文明）的存续依赖于负熵流的获取。
形式化表述
$$\text{Survival}(\text{ComplexSystem}) \Rightarrow \exists \text{NegentropicFlow}$$

[B] 与新生命观的关系
此规则是新生命观（NL-2）的物理学基础：
$$\text{NL-2}: \text{生命是维持负熵的自组织过程}$$

[B] D.2.1.3 热力学边界的规范性含义

[B] 规则D.2.4（热力学规范性）
热力学约束对规范性框架施加以下边界：

[B] | 边界 | 描述 | 规范性含义 |
|------|------|------------|
| 能量边界 | 可用能量有限 | 需要能量分配规范 |
| 熵边界 | 熵增不可逆 | 某些损害不可恢复 |
| 负熵边界 | 负熵获取有成本 | 维护复杂性需要资源 |

[B] D.2.2 信息论约束规则

[B] D.2.2.1 信息处理边界

[B] 规则D.2.5（朗道尔原理）
信息擦除具有最小能量成本。
形式化表述
$$E_{\min} = k_B T \ln 2 \text{ per bit erased}$$
其中 $k_B$ 是玻尔兹曼常数，$T$ 是温度。

[B] 应用含义

[B] | 含义 | 描述 |
|------|------|
| 计算成本 | 计算存在最小能量成本 |
| 信息保存 | 信息保存需要能量 |
| 遗忘成本 | "遗忘"也有热力学成本 |

[B] D.2.2.2 信道容量边界

[B] 规则D.2.6（香农定理）
信道的最大传输速率受信道容量限制。
形式化表述
$$C = B \log_2(1 + \frac{S}{N})$$
其中 $C$ 是信道容量，$B$ 是带宽，$S/N$ 是信噪比。

[B] 应用含义

[B] | 含义 | 描述 |
|------|------|
| 通信限制 | 星际通信受距离和能量限制 |
| 协调限制 | 大规模协调受信息传输限制 |
| 延迟约束 | 信息传输存在延迟（光速限制） |

[B] D.2.2.3 信息守恒

[B] 规则D.2.7（信息守恒）
在封闭系统中，信息（量子意义上）是守恒的。
形式化表述
$$\text{UnitaryEvolution}: |\psi(t_1)\rangle = U|\psi(t_0)\rangle, U^\dagger U = I$$

[B] 应用含义

[B] | 含义 | 描述 |
|------|------|
| 信息追溯 | 原则上信息可以追溯 |
| 实践限制 | 但热力学噪声使追溯在实践中通常不可行 |

[B] 规则D.4.1（RFP定义）

| 多主体约束 | 考虑对所有受影响主体的影响 |
