# 📰 ICS Daily Commentary 发布系统 - 快速开始指南

## 概述

**完全自动化的中英文双语发布系统** ✨

- 🔄 **一次填写，双语同步发布**（英文 + 中文）
- 📦 **自动备份历史**（每天自动保存，永不丢失）
- 📚 **自动生成归档**（访客可浏览历史评论）
- 🚀 **一键部署**（git自动提交推送）

```powershell

```

## 💡 内容填写要点

### 必填字段（12个）

| 字段 | 含义 | 示例 |
|------|------|------|
| **date** | 发布日期 | "March 4, 2025" (EN) / "2025年3月4日" (ZH) |
| **category** | 新闻分类 | "AI & Governance" |
| **headline** | 新闻标题 | "Major breakthrough in..." |
| **source** | 新闻来源 | "Nature, Reuters" |
| **sourceTime** | 来源时间 | "2025-03-04T09:30:00Z" |
| **summary** | 新闻摘要 | 3-5句话概括 |
| **newThreeViews** | 新三观分析 | 用新认知观、新生命观、新宇宙观分析 |
| **normative** | 规范原则评估 | 引用RFP/NRP/REV等原则 |
| **longTermImpact** | 长期影响 | 100-1000年视角 |
| **reflectionQ1** | 思考问题1 | 开放式问题 |
| **reflectionQ2** | 思考问题2 | 开放式问题 |
| **tags** | 标签（5-7个） | ["AI", "Ethics", "Future"] |

## 🛠️ 常见问题

### Q: 脚本提示"不在git仓库中"
**A:** 使用 `-Deploy` 前，确保已在git仓库初始化：
```powershell
cd c:\Users\Administrator\Documents\ics-website
git init
git remote add origin <repo-url>
```

### Q: 字段值中包含特殊字符（如引号）会出错
**A:** 脚本会自动转义。但为安全起见，避免在JSON中直接使用未转义的特殊字符。

### Q: 如何手动修改已发布的内容？
**A:** 直接编辑对应HTML文件的内容块。但建议改正信息源后重新发布。

### Q: 历史文件在哪？
**A:** 
- 英文：`public/en/news/news-daily-YYYYMMDD.html`
- 中文：`public/zh/news/news-daily-YYYYMMDD.html`

### Q: 如何生成归档索引？
**A:** 脚本自动生成。每次发布时，`Update-ArchiveIndex` 函数扫描 `news/` 目录并更新索引页。

```
      ↓

      ↓
[PowerShell脚本]
      ├→ Archive-PreviousCommentary()
      │  └→ news-daily-YYYYMMDD.html

  ├→ public/en/daily-commentary.html

```
