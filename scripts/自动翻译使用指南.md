# 🌐 自动翻译功能使用指南

## 概述

现在你可以**只填写中文内容**，脚本会自动调用 OpenAI API 翻译成英文！

---

## 🚀 快速开始

### 方式1：使用纯中文JSON

```powershell
# 1. 填写纯中文JSON（已提供模板）
notepad scripts\daily-commentary-chinese-only.sample.json

# 2. 运行自动翻译脚本
.\scripts\publish-daily-commentary-v3-auto-translate.ps1 `
    -ContentFile scripts\daily-commentary-chinese-only.sample.json `
    -AutoTranslate `
    -Deploy
```

### 方式2：环境变量配置

```powershell
# 设置API密钥（推荐方式，只需设置一次）
$env:OPENAI_API_KEY = "sk-your-api-key-here"

# 然后直接运行
.\scripts\publish-daily-commentary-v3-auto-translate.ps1 `
    -ContentFile your-chinese-content.json `
    -AutoTranslate `
    -Deploy
```

---

## 📋 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `-ContentFile` | ✅ | JSON文件路径 |
| `-AutoTranslate` | ❌ | 启用自动翻译（如JSON只有中文） |
| `-OpenAIKey` | ❌ | API密钥（优先级高于环境变量） |
| `-Deploy` | ❌ | 自动git提交部署 |

## 📝 纯中文JSON模板

模板位置：`scripts/daily-commentary-chinese-only.sample.json`

```json
{
  "zh": {
    "date": "2026年3月4日",
    "category": "人工智能",
    "headline": "OpenAI发布GPT-5：通用人工智能的新里程碑",
    "source": "OpenAI官方博客",
    "sourceTime": "2026-03-04 09:00",
    "summary": "...",
    "newThreeViews": "...",
    "normative": "...",
    "longTermImpact": "...",
    "reflectionQ1": "...",
    "reflectionQ2": "...",
    "tags": ["通用人工智能", "GPT-5", "递归自由"]
  }
}
```

**注意**：只需填写 `zh` 部分，`en` 部分会自动生成！

## 🔑 获取 OpenAI API 密钥

### 方法1：OpenAI官方
1. 访问 https://platform.openai.com/api-keys
2. 创建新API密钥
3. 复制密钥（格式：`sk-proj-...`）

### 方法2：Azure OpenAI
可修改脚本中的API端点，使用Azure服务（国内更稳定）

### 方法3：其他兼容API
任何OpenAI兼容的API都可使用（如本地Ollama、智谱AI等）

## ⚙️ 工作流程

```
1. 读取纯中文JSON
   ↓
2. 检测到 -AutoTranslate 标志
   ↓
3. 调用 OpenAI API 翻译12个字段
   ├─ headline (新闻标题)
   ├─ summary (摘要)
   ├─ newThreeViews (新三观分析)
   ├─ normative (规范原则)
   ├─ longTermImpact (长期影响)
   ├─ reflectionQ1/Q2 (反思问题)
   └─ tags (标签数组)
   ↓
4. 自动填充 en 对象
   ↓
5. 继续正常发布流程
   ├─ 归档旧内容
   ├─ 更新页面
   ├─ 同步首页卡片
   └─ git部署（可选）
```

## 🔍 使用示例

### 完整命令（推荐）

```powershell
# 设置API密钥
$env:OPENAI_API_KEY = "sk-proj-..."

# 创建今天的中文内容
$today = Get-Date -Format "yyyy-MM-dd"
$contentFile = "scripts\daily-commentary-$today-zh.json"

# 复制模板并编辑
Copy-Item scripts\daily-commentary-chinese-only.sample.json $contentFile
notepad $contentFile

# 翻译并发布
.\scripts\publish-daily-commentary-v3-auto-translate.ps1 `
    -ContentFile $contentFile `
    -AutoTranslate `
    -Deploy
```

### 仅翻译不部署

```powershell
.\scripts\publish-daily-commentary-v3-auto-translate.ps1 `
    -ContentFile your-content.json `
    -AutoTranslate
```

### 使用双语JSON（不需要翻译）

```powershell
# 如果JSON已经包含en和zh，不使用-AutoTranslate
.\scripts\publish-daily-commentary-v3-auto-translate.ps1 `
    -ContentFile scripts\daily-commentary.sample.json `
    -Deploy
```

## 🛠️ 故障排查

### 问题1：API密钥未找到
```
⚠ No OpenAI API key found
```
**解决**：设置环境变量或使用 `-OpenAIKey` 参数

### 问题2：翻译失败
```
✗ Translation failed for 'headline'
```
**解决**：
- 检查API密钥是否有效
- 检查网络连接
- 确认API额度充足

### 问题3：仍使用原中文
**原因**：API调用失败时会保留中文原文
**解决**：查看错误信息，修复后重新运行
