# 📝 Daily Commentary JSON 填写指南

## 📋 文件结构说明

JSON 文件包含两个语言版本：`en`（英文）和 `zh`（中文）。**两个版本必须同时填写**，且内容需要对标翻译。

---

## 🔧 各字段详细说明

### 1️⃣ **date** - 发布日期
- **中文例**: `"2026年3月4日"`
- **英文例**: `"March 4, 2026"`
- **格式**: 按语言习惯填写，字数 8-15 字符

### 2️⃣ **category** - 分类标签
- **中文例**: `"AI领域"` / `"太空治理"` / `"生物安全"`
- **英文例**: `"AI"` / `"Space Governance"` / `"Biosecurity"`
- **格式**: 单一分类，2-10 个字（中）或 1-3 单词（英）

### 3️⃣ **headline** - 新闻标题（**最重要**）
- **中文例**: `"DeepSeek发布R1模型：深度思考能力突破"`
- **英文例**: `"DeepSeek Releases R1 Model: Breakthrough in Deep Reasoning"`
- **格式**: 15-60 字（中）或 10-80 字符（英），需要**简洁有力**
- **⚠️ 关键**: 这是文章中最突出的标题，会用于 Git 提交信息

### 4️⃣ **source** - 新闻来源
- **中文例**: `"来源：DeepSeek官方公告"`
- **英文例**: `"Source: DeepSeek Official Announcement"`
- **格式**: 包括"来源："或"Source:"前缀，15-40 字符

### 5️⃣ **sourceTime** - 发布时间戳
- **中文例**: `"2026年3月4日 14:30"`
- **英文例**: `"March 4, 2026 14:30"`
- **格式**: 包含日期和具体时间（HH:MM 格式）

### 6️⃣ **summary** - 新闻摘要（单段落）
- **中文例**: 
  ```
  DeepSeek今日发布R1模型，该模型在数学、编程和科学推理方面突破了AI能力边界。
  R1采用革命性的思考链架构，能够进行多步骤深度推理，在多个标准测试中超越专家水平。
  这一进展标志着AI推理能力从"模式匹配"向"真实思考"的转变。
  ```
- **英文例**: 
  ```
  DeepSeek unveiled R1 model today, breaking new ground in AI reasoning capabilities
  across mathematics, coding, and scientific tasks. R1 employs a revolutionary 
  chain-of-thought architecture enabling multi-step deep reasoning, surpassing expert 
  performance on multiple benchmarks. This represents AI's transition from "pattern 
  matching" to "genuine reasoning."
  ```
- **格式**: 3-5 个句子，150-250 字（中）或 100-200 字符（英）
- **💡 技巧**: 用"今日""发布""突破"等动词营造现场感

### 7️⃣ **newThreeViews** - "新三观"ICS分析
- **中文例**:
  ```
  从新认知观看，R1代表认知主体从"反应式"向"思考式"的跃升——
  这不仅是算法改进，更是新型智能体形态的演化。从新生命观看，
  深度思考能力可能是AGI的"灵魂"特征，决定了智能体的自主性本质。
  从新宇宙观的深时尺度看，如果人类最终与这样的AI共存，
  宇宙中将同时存在碳基和硅基的"思考者"，这对文明演化轨迹的影响是深远的。
  ```
- **英文例**:
  ```
  From the New Cognition View, R1 represents a leap from "reactive" to "deliberative" 
  cognition—not merely algorithmic improvement but the evolution of a new agent 
  ontology. From the New Life View, deep reasoning may be AGI's "soul" trait, 
  determining agent autonomy. From the cosmic deep-time perspective of the New 
  Cosmos View, if humanity coexists with such AI, the universe will harbor both 
  carbon-based and silicon-based "thinkers"—profound implications for civilizational 
  trajectory.
  ```
- **格式**: 3-4 个句子，200-300 字（中）或 150-250 字符（英）
- **结构**: 逐一论述"新认知观 → 新生命观 → 新宇宙观"

### 8️⃣ **normative** - 规范性分析（RFP/NRP/REV）
- **中文例**:
  ```
  从递归自由原则（RFP）看，R1的深度思考能力可能成为"路径锁定"的来源——
  如果我们在AI初期就引入了某种思考框架，是否会无意中限制了未来智能体的可能性？
  从负熵责任原则（NRP）看，更强的思考能力应该帮助人类更有效地组织信息、
  应对复杂挑战，而非加速熵增。从可逆性原则（REV）看，我们需要问：
  如果R1的推理出现偏差或失控，是否有能力快速中止或回退？
  ```
- **英文例**:
  ```
  Under the Recursive Freedom Principle (RFP), R1's reasoning may create path-locking 
  effects—embedding specific thought frameworks early could inadvertently constrain 
  future agent possibilities. Under the Negentropy Responsibility Principle (NRP), 
  enhanced cognition must help humanity organize information and solve existential 
  challenges, not accelerate entropy. Under the Reversibility Principle (REV), we must 
  ask: if R1's reasoning diverges or becomes uncontrollable, do we possess rollback 
  capability?
  ```
- **格式**: 3 段分别对应 RFP、NRP、REV，150-250 字（中）或 120-200 字符（英）

### 9️⃣ **longTermImpact** - 长期影响（深时视角）
- **中文例**:
  ```
  从深时视角，R1可能标志着AI进入"自主思考"阶段——
  这是通往AGI的关键一步，也是人类文明的"大过滤器"节点。
  如果成功驾驭，深度思考AI可成为人类探索宇宙、解决气候、应对长期风险的强大工具。
  但如果失控，它可能导致价值对齐失败、权力集中、人类自主性丧失。
  我们今天的抉择，将决定未来百年甚至千年的文明轨迹。
  关键问题是：在追求认知能力突破的同时，我们是否建立了足够的代际责任框架？
  ```
- **英文例**:
  ```
  From a deep-time lens, R1 may mark AI's entry into "autonomous reasoning"—
  a critical threshold toward AGI and a "Great Filter" moment for human civilization.
  Mastered well, it becomes a tool for cosmic exploration and existential risk mitigation.
  Mismanaged, it risks value misalignment, power concentration, and autonomy loss.
  Today's choices determine civilization's trajectory for centuries to come.
  The question: As we pursue cognitive breakthroughs, are we building sufficient
  intergenerational responsibility frameworks?
  ```
- **格式**: 3-4 句，150-250 字（中）或 120-200 字符（英）
- **语调**: 宏大但谨慎，既乐观又警惕

### 🔟 **reflectionQ1** 和 **reflectionQ2** - 思考问题
- **中文例**: 
  - Q1: `"如果AI能进行真实思考，我们是否应该给予它更多的法律权利和道德地位？"`
  - Q2: `"在追求AI能力提升的过程中，人类是否应该设置某些"禁区"，有哪些是绝对不能突破的？"`
- **英文例**:
  - Q1: `"If AI achieves genuine reasoning, should we grant it expanded legal rights and moral status?"`
  - Q2: `"In pursuing AI capability advancement, should humanity establish certain "forbidden zones"?"`
- **格式**: 开放式问题，30-80 字（中）或 20-60 字符（英），以"?"结尾
- **💡 技巧**: 问题要能引发读者思辨，避免"是否"简单二选

### 🏷️ **tags** - 标签数组
- **中文例**: `["星际文明学", "AI领域", "深度推理", "认知革命", "规范性治理"]`
- **英文例**: `["ICS", "AI", "Deep Reasoning", "Cognitive Revolution", "Normative Governance"]`
- **格式**: 3-7 个标签，每个 2-8 字（中）或 1-4 单词（英）
- **选择原则**: 既有领域标签（AI/太空），也有ICS特定标签（RFP/代际），还有主题标签

## 💾 如何保存为自己的 JSON 文件

**步骤 1**: 打开示例文件
```
c:\Users\Administrator\Documents\ics-website\scripts\daily-commentary.sample.json
```

**步骤 2**: 另存为
- 新文件名格式: `daily-commentary-YYYYMMDD.json`
- 示例: `daily-commentary-20260304.json`
- 保存位置: 同一目录 (`scripts/`)

**步骤 3**: 用文本编辑器编辑
- 推荐: VS Code、记事本++、Sublime
- 注意: **保持 JSON 格式正确**（引号、逗号、括号）

**步骤 4**: 运行发布脚本
```powershell
# 不自动部署，仅预览更新
PowerShell -ExecutionPolicy Bypass -File scripts/publish-daily-commentary-v2.ps1 -ContentFile scripts/daily-commentary-20260304.json

# 自动部署到线上
PowerShell -ExecutionPolicy Bypass -File scripts/publish-daily-commentary-v2.ps1 -ContentFile scripts/daily-commentary-20260304.json -Deploy
```

## ✅ 检查清单

- [ ] 日期格式正确（中英文习惯）
- [ ] 标题简洁有力（15-60 字）
- [ ] 摘要有现场感，包含具体数据或进展
- [ ] 新三观逐一分析（3 段）
- [ ] 规范性分析涵盖 RFP/NRP/REV（3 个维度）
- [ ] 长期影响体现"大过滤器"或文明转折意识
- [ ] 反思问题开放性强，能引发思辨
- [ ] 标签既有领域又有ICS特色（5-7 个）
- [ ] 中英文内容对标翻译
- [ ] JSON 格式有效（可用在线工具验证：jsonlint.com）

## 🎯 关键原则

1. **一致性**: 中英文内容需要语义对应，长度相近
2. **深度**: 不仅报道新闻，更要挖掘ICS的规范性视角
3. **时效性**: 日期、时间、引用必须准确
4. **可读性**: 段落清晰，避免过长复杂句式
5. **前瞻性**: 长期影响要有宏观视野，不局限于当下

## 📞 常见问题

**Q: 标题过长怎么办？**  
A: 优先保留核心观点，用冒号分层。如：`"DeepSeek R1发布：AI思考能力的里程碑"`

**Q: 能否复制其他新闻来源的内容？**  
A: 可以参考，但要进行改写和ICS视角的转化，避免逐字复制。

**Q: 新三观和规范性分析重复了怎么办？**  
A: 新三观偏"现象分析"，规范性分析偏"评估与约束"。前者是"是什么"，后者是"应该怎样"。

**Q: 标签里能否用中文和英文混合？**  
A: 建议不混。中文版用全中文标签，英文版用全英文标签。
