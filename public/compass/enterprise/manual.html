2. Compliance Assessment Matrix / 合规评估矩阵

The Compliance Matrix cross-references your organization's products/systems against all 5 ICS Forbidden Red Lines (FRL-1 through FRL-5).

How to Use / 使用方法

01
Navigate to Compliance → New Matrix
02
Enter your product/system names (or import from CSV)
03
For each product × FRL intersection, assess: Pass / Warning / Fail / Not Assessed
04
Add notes and assign a responsible assessor per cell
05
Export the matrix as PDF, CSV, or JSON for audit records

11. FAQ / 常见问题

Q: Can we host ICS Compass on our own servers? / 可以私有部署吗？

Yes. Enterprise clients receive access to the self-hosted deployment package. The application runs entirely in-browser with no external data dependencies — your evaluation data never leaves your infrastructure.

Q: Is the API rate-limited? / API有速率限制吗？

Enterprise API plans include customizable rate limits. Standard enterprise tier: 10,000 evaluations/day. Contact sales for higher volumes.

Q: Can we create custom red lines or metrics? / 可以创建自定义红线或指标吗？

Custom evaluation templates with custom scoring criteria are supported. Custom fundamental metrics (beyond the 6 ICS metrics) are available in the Enterprise Plus tier — contact sales for details.
