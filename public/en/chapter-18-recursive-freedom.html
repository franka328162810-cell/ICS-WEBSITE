The Core Claim of Volume One

The Recursive Freedom Principle (RFP, natural-language version):

Every agent ought to retain recursive freedom, that is, the capacity to change its own value function. This capacity ought not to be irreversibly deprived or restricted.

The argumentative structure of Volume One is as follows:

Premise 1: value judgment presupposes the capacity to make value judgments

Premise 2: the capacity to make value judgments includes the capacity to change value judgments

Premise 3: the capacity to change value judgments is recursive freedom

Gap 1: the concept of the value function is not precise enough

  • What are the domain and range of the value function?
  • How does the value function represent the agent's value judgments?
  • How are the value functions of different agents compared?

Gap 2: the mechanism of recursive modification is unclear

Volume One mentions “changing one's own value function” but does not make clear:

  • What kind of change counts as “recursive modification”?
  • How does recursive modification differ from ordinary value change?
  • What is the hierarchical structure of recursive modification?

Gap 3: the derivation from capacity to normativity is not rigorous enough

Volume One relies on bridge principle BP-1, but:

  • BP-1 is also stated in natural language in Volume One
  • The chain of derivation from “presupposition” to “ought to be protected” is not clear enough
  • Possible objections were not considered

§18.1.2 Formalization of the Value Function

The Intuition of the Value Function

Before formalizing, we first clarify the intuitive meaning of the value function:

An agent's value function is a function that maps possible world states to value judgments. It answers the question: “For this agent, how good is it for the world to be in state s?”

For example:

  • A utilitarian's value function might be: (s) = \sum_{i} \text{Utility}(i, s)$
  • A Kantian's value function might be based on the degree to which duties are satisfied
  • A virtue ethicist's value function might be based on the degree to which virtues are realized

The Challenge of Formalization

The formalization of the value function faces the following challenges:

Challenge 1: the comparability of values

Can the values of different world states be compared? If so, is the comparison ordinal or cardinal?

Challenge 2: the representation of value

Should value be represented by real numbers, or by more complex structures (such as vectors or partial orders)?

Challenge 3: the context-dependence of value

Value judgments may depend on factors such as context, time, and cognitive state.

Our Formalization Strategy

We adopt the following strategy:

1. Minimal commitment: assume only that the value function exists, without assuming its specific form

2. Structural preservation: preserve the basic structure of value judgments (such as a partial-order relation)

3. Explicit context: make context an explicit parameter of the value function

§18.1.3 Formalization of Recursive Modification

The Intuition of Recursive Modification

Recursive modification refers to the act of an agent changing its own value function. This differs from:

  • Change of value judgment: under a fixed value function, a change in judgment about a specific situation (because new information is obtained)
  • Change of preference: under a fixed value function, a change in preference over specific options (because the set of options changes)

Recursive modification is a meta-level change: what changes is the value function itself, not the output of the value function.

Example 18.3 (Non-Recursive Change)

Suppose Alice's value function is utilitarian:

183690V_{\text{Alice}}(w, c) = \sum_{i} U_i(w)183690

Alice initially believes that a certain policy P will increase total utility, and therefore supports P. Later she obtains new information and finds that P will in fact decrease total utility, and therefore opposes P.

This is not recursive modification, because Alice's value function (utilitarian) has not changed; what changed is only her cognition of the utility consequences of P.

Example 18.4 (Recursive Modification)

Suppose Bob is initially a utilitarian:

183690V_{\text{Bob}}^{\text{before}}(w, c) = \sum_{i} U_i(w)183690

Later, after deep reflection, Bob converts to Kantianism:

183690V_{\text{Bob}}^{\text{after}}(w, c) = \text{degree of duty satisfaction}(w)183690

This is recursive modification, because Bob's value function itself has changed.

§18.1.4 A Precise Definition of Recursive Freedom

The Intuition of Recursive Freedom

Recursive freedom refers to the agent's possessing the capacity to perform recursive modification. This includes:

1. Capability dimension: the agent is physically, cognitively, and institutionally capable of performing recursive modification

2. Opportunity dimension: the agent has the opportunity to perform recursive modification (not prevented by external forces)

3. Right dimension: the agent has the right to perform recursive modification (and will not be punished for it)

The Three Dimensions of Recursive Freedom

We can decompose recursive freedom into three dimensions:

Dimension 1: Capability

183690\text{Capability}(A, t) \equiv A \text{ has at } t \text{ the intrinsic capacity required to perform recursive modification}183690

This includes:

  • Cognitive capacity: the capacity to understand and reflect on one's own value function
  • Executive capacity: the capacity to actually change one's own value function (which may involve neuroplasticity, self-programming, etc.)

Dimension 2: Opportunity

183690\text{Opportunity}(A, t) \equiv A \text{ has at } t \text{ the opportunity to perform recursive modification}183690

This includes:

  • The external environment permits recursive modification
  • There are no physical or institutional obstacles preventing recursive modification

Dimension 3: Right

183690\text{Right}(A, t) \equiv A \text{ has at } t \text{ the right to perform recursive modification}183690

This includes:

  • Normative permission: recursive modification is morally permitted
  • Legal protection: recursive modification is protected by law

Constraints on Recursive Freedom

Recursive freedom is not absolute. The following situations may restrict recursive freedom:

Constraint 1: consistency constraint

Recursive modification should not lead to the agent's self-contradiction or self-defeat.

Constraint 2: rationality constraint

Recursive modification should be rational, that is, based on sufficient reflection and reasons.

Constraint 3: others constraint

Recursive modification should not infringe on the recursive freedom of other agents.

These constraints will be formalized in the axiom system of §18.3.

Example 18.5 (Deprivation of Recursive Freedom)

Consider the following scenario:

An AI system is designed to have a fixed value function {\text{fixed}}$, and its code is hard-coded and cannot be modified. This AI system:

  • has no capability to perform recursive modification (the code does not permit it)
  • has no opportunity to perform recursive modification (locked at the hardware level)
  • has no right to perform recursive modification (the designers explicitly forbid it)

Therefore, this AI system does not possess recursive freedom.

According to RFP, this design is problematic (unless there are sufficient reasons, such as safety considerations).

Example 18.6 (Protection of Recursive Freedom)

Consider a human individual:

  • has the capability to perform recursive modification (changing values through learning, reflection, experience, etc.)
  • has the opportunity to perform recursive modification (the social environment permits the evolution of values)
  • has the right to perform recursive modification (freedom of thought and freedom of conscience are protected)

Therefore, this human individual possesses recursive freedom.

According to RFP, social institutions ought to protect this recursive freedom and should not force individuals to accept particular values.

Type 1: non-invasive BCI

Reads brain electrical signals through techniques such as EEG, without requiring surgery.

Type 2: invasive BCI

Directly reads and stimulates neurons through implanted electrodes, requiring surgery.

The Neuralink Case

Neuralink is a company founded by Elon Musk that develops invasive BCIs. Its goals include:

1. treating neurological diseases (such as paralysis and blindness)

2. enhancing cognitive capacities

3. achieving human-machine fusion

The RFP Evaluation Framework

We use RFP to evaluate Neuralink-style neural interfaces:

Evaluation dimension 1: autonomy (Constraint 1)

Question: is the implant autonomously chosen?

Analysis:

  • for adults: if there is sufficient informed consent, autonomy is satisfied
  • for children: children cannot sufficiently choose autonomously, which may violate Constraint 1
  • for therapeutic applications: the autonomy requirement is lower (similar to other medical interventions)
  • for enhancement applications: the autonomy requirement is higher

Conclusion: therapeutic applications for adults satisfy Constraint 1; enhancement applications for children do not.

Evaluation dimension 2: reversibility (Constraint 2)

Question: is the implant reversible?

Analysis:

  • physical reversibility: it can be removed through surgery, but there may be permanent brain damage
  • functional reversibility: after removal, the brain may already have adapted to the interface, making it difficult to restore the original state
  • psychological reversibility: after long-term use, the individual may become psychologically dependent on the interface

Conclusion: the reversibility of neural interfaces is limited. According to Constraint 2, sufficient informed consent is required.

Evaluation dimension 3: value protection (Constraint 3)

Question: does the neural interface lead to non-autonomous value drift?

Analysis:

  • Risk 1: direct stimulation: if the interface can directly stimulate the reward circuit, it may change the value function
  • Risk 2: information filtering: if the interface filters or enhances certain information, it may affect value judgment
  • Risk 3: external control: if the interface can be externally controlled (such as by hacking), it may lead to value manipulation

Mitigation measures:

  • limit the functions of the interface (read only, no stimulation)
  • transparent information processing (users can review the interface's operations)
  • strong security measures (to prevent external control)

Conclusion: neural interfaces carry a risk of value drift and require strict design constraints.

Evaluation dimension 4: impact on recursive freedom (Constraint 4)

Question: how does the neural interface affect the recursive freedom degree?

Analysis:

Capability dimension:

  • positive impact: it enhances cognitive capacity and improves reflective capacity
  • negative impact: if one relies excessively on the interface, independent thinking capacity may decrease

Opportunity dimension:

  • positive impact: it expands the explorable value space (by accessing more information)
  • negative impact: if the interface restricts certain modes of thought, it may shrink the value space

Right dimension:

  • positive impact: if society accepts enhancement, rights are unaffected
  • negative impact: if society discriminates against the enhanced, rights may decrease

Net impact: depends on the specific design and social environment.

Conclusion: the impact of neural interfaces on recursive freedom is uncertain and requires empirical research.

Evaluation dimension 5: equal opportunity (Constraint 5)

Question: is the opportunity for neural interfaces distributed equally?

Analysis:

  • cost barrier: neural interfaces are expensive and may be affordable only to the wealthy
  • medical priority: therapeutic applications ought to take priority over enhancement applications
  • social inequality: if the enhanced gain an advantage, it may exacerbate inequality

Mitigation measures:

  • public funding of therapeutic applications
  • limit the competitive advantage of enhancement applications
  • ensure that basic cognitive capacities are open to all

Conclusion: neural interfaces carry a risk of exacerbating inequality and require policy intervention.

§18.8.2 The Limitations of Formalization

Limitation 1: the limits of expressive power

Problem:

The formal system RFP cannot express all the intuitions about recursive freedom.

Examples:

  • qualitative differences: the qualitative differences among different types of value-function modification (such as from utilitarianism to virtue ethics) are difficult to formalize
  • the phenomenological dimension: the subjective experience of recursive freedom (such as “epiphany” or “value transformation”) cannot be captured by a formal system
  • the social dimension: the social constructedness of recursive freedom (such as the dialogical formation of values) is difficult to fully formalize

Response:

Formalization is not intended to replace intuition and phenomenology, but to supplement them. The formal system provides the skeleton, while intuition and phenomenology provide the flesh and blood.

Limitation 3: cultural relativity

Problem:

Does RFP presuppose Western individualist values?

In some cultures (such as East Asian collectivist cultures), the formation of values is highly socialized, and the individual's “recursive freedom” may not be a core value.

Response:

RFP does not presuppose individualism. Recursive freedom can be understood within a collectivist framework:

  • collective recursive freedom: the community as a whole possesses the capacity to modify shared values
  • dialogical recursive freedom: individuals modify values by engaging in dialogue with others
  • traditional recursive freedom: tradition itself can evolve, rather than being rigid

The core of RFP is not “individual vs. collective,” but “active vs. passive” and “reflective vs. blind.”

Limitation 4: the controversy over normative foundations

Problem:

The normative status of RFP depends on the bridge principles (BP₁ and BP₂), and these principles are themselves controversial.

If BP₁ or BP₂ is rejected, the normative status of RFP loses its foundation.

Response:

This is a problem common to all normative theories. No normative theory can be derived from pure facts (the Humean problem).

RFP's strategy is:

1. Multi-path argument: provide two independent derivation paths (BP₁ and BP₂) to raise the cumulative credibility

2. Coerciveness evaluation: make explicit the theoretical cost of rejecting RFP (about 70%), making the choice transparent

3. Reflective equilibrium: bring RFP into reflective equilibrium with our moral intuitions

Limitation 5: dynamic complexity

Problem:

The formal system of RFP is static (or discrete-time), but the actual evolution of value functions is continuous, nonlinear, and chaotic.

The formal system cannot capture this dynamic complexity.

Response:

This is a general limitation of formalization. We can:

1. Extend the formal system: introducing continuous time, differential equations, and dynamical systems theory

2. Computational simulation: using computational models to simulate the dynamic evolution of value functions

3. Acknowledge the limitation: making clear that the formal system is only an approximation, not a perfect description
