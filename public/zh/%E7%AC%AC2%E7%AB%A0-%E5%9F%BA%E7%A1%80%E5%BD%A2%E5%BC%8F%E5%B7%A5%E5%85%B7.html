§2.1 逻辑基础

§2.1.1 一阶逻辑（First-Order Logic）

为什么需要一阶逻辑？

一阶逻辑是数学和哲学形式化的标准工具。它提供：

  • 量词（∀, ∃）：表达"所有"和"存在"
  • 谓词：表达对象的属性和关系
  • 函数：表达对象之间的映射

语法：

基本符号：

  • 变量：x, y, z, ...
  • 常量：a, b, c, ...
  • 函数符号：f, g, h, ...
  • 谓词符号：P, Q, R, ...
  • 逻辑连接词：∧, ∨, →, ↔, ¬
  • 量词：∀, ∃
  • 等号：=

项（Terms）：

```

t ::= x | c | f(t₁, ..., tₙ)

```

公式（Formulas）：

```

φ ::= P(t₁, ..., tₙ) | t₁ = t₂ | ¬φ | φ ∧ ψ | φ ∨ ψ | φ → ψ | ∀x φ | ∃x φ

```

语义：

结构（Structure）：

M = (D, I)

  • D：论域（非空集合）
  • I：解释函数
  • I(c) ∈ D（常量的解释）
  • I(f): Dⁿ → D（函数的解释）
  • I(P) ⊆ Dⁿ（谓词的解释）

满足关系（Satisfaction）：

  • M ⊨ P(t₁, ..., tₙ) iff (I(t₁), ..., I(tₙ)) ∈ I(P)
  • M ⊨ ¬φ iff M ⊭ φ
  • M ⊨ φ ∧ ψ iff M ⊨ φ and M ⊨ ψ
  • M ⊨ ∀x φ iff for all d ∈ D, M[x:=d] ⊨ φ

推理规则：

自然演绎系统：

[引入规则]

∧-引入： φ ψ

-----

φ ∧ ψ

∀-引入： φ[x] (x不在假设中自由出现)

-----

∀x φ

[消去规则]

∧-消去： φ ∧ ψ φ ∧ ψ

----- -----

φ ψ

∀-消去： ∀x φ

-----

φ[t/x]

重要元定理：

定理2.1（可靠性）： 如果 ⊢ φ，则 ⊨ φ

定理2.2（完备性，哥德尔）： 如果 ⊨ φ，则 ⊢ φ

定理2.3（紧致性）： 如果Γ的每个有限子集可满足，则Γ可满足

在本书中的应用：

  • 本体论的基本结构（第四至六章）
  • 认识论的基本关系（第七至九章）
  • 规范性的基本表述（第十至十二章）

Coq中的一阶逻辑：

```coq

( 全称量化 )

Theorem forall_example : forall (A : Type) (P : A -> Prop),

(forall x, P x) -> forall y, P y.

Proof.

intros A P H y.

apply H.

Qed.

( 存在量化 )

Theorem exists_example : forall (A : Type) (P : A -> Prop) (x : A),

P x -> exists y, P y.

Proof.

intros A P x H.

exists x.

exact H.

Qed.

```

§2.1.2 模态逻辑（Modal Logic）

为什么需要模态逻辑？

模态逻辑扩展一阶逻辑，增加：

  • 必然性算子（□）：表达"必然"
  • 可能性算子（◇）：表达"可能"

这对于表述规范性至关重要。

语法：

在一阶逻辑基础上增加：

φ ::= ... | □φ | ◇φ

语义：可能世界语义（Kripke语义）

框架（Frame）：

F = (W, R)

  • W：可能世界的集合
  • R ⊆ W × W：可达关系

模型（Model）：

M = (W, R, V)

  • V：赋值函数，V(p, w) ∈ {true, false}

满足关系：

  • M, w ⊨ □φ iff for all w' such that wRw', M, w' ⊨ φ
  • M, w ⊨ ◇φ iff there exists w' such that wRw' and M, w' ⊨ φ

模态逻辑系统：

系统K（最弱）：

K公理：□(φ → ψ) → (□φ → □ψ)

必然化规则：如果 ⊢ φ，则 ⊢ □φ

系统T：

K + T公理：□φ → φ

对应：R是自反的

系统S4：

T + 4公理：□φ → □□φ

对应：R是自反且传递的

系统S5（最强）：

S4 + 5公理：◇φ → □◇φ

对应：R是等价关系

我们的选择：S5

理由：

  • S5适合表述规范性的模态结构
  • S5的可能世界都是相互可达的
  • S5有简洁的语义和完备的证明系统

在本书中的应用：

  • 规范原则的模态结构（第十章）
  • 可能性空间的形式化（第二十三章）

Coq中的模态逻辑：

```coq

( 可能世界的定义 )

Parameter World : Type.

Parameter R : World -> World -> Prop.

( 必然性 )

Definition Box (P : World -> Prop) (w : World) : Prop :=

forall w', R w w' -> P w'.

( 可能性 )

Definition Diamond (P : World -> Prop) (w : World) : Prop :=

exists w', R w w' /\ P w'.

( S5的等价关系性质 )

Axiom R_reflexive : forall w, R w w.

Axiom R_symmetric : forall w w', R w w' -> R w' w.

Axiom R_transitive : forall w w' w'', R w w' -> R w' w'' -> R w w''.

```

§2.1.3 道义逻辑（Deontic Logic）

为什么需要道义逻辑？

道义逻辑专门研究义务、许可、禁止等规范概念。

基本算子：

  • O(φ)：有义务做φ
  • P(φ)：许可做φ
  • F(φ)：禁止做φ

关系：

P(φ) ≝ ¬O(¬φ) (许可 = 没有义务不做)

F(φ) ≝ O(¬φ) (禁止 = 有义务不做)

标准道义逻辑（SDL）：

公理：

D1: O(φ → ψ) → (O(φ) → O(ψ)) [K公理的道义版本]

D2: ¬O(⊥) [义务一致性]

D3: O(φ) → P(φ) [义务蕴含许可]

推理规则：

RE (规则等价): 如果 ⊢ φ ↔ ψ，则 ⊢ O(φ) ↔ O(ψ)

RN (规则必然化): 如果 ⊢ φ，则 ⊢ O(φ)

可能世界语义：

道义模型：

M = (W, R_O, V)

  • W：可能世界
  • R_O：道义可达关系（w R_O w' 表示w'是w的道义理想世界）
  • V：赋值函数

满足关系：

M, w ⊨ O(φ) iff for all w' such that w R_O w', M, w' ⊨ φ

SDL的问题：

问题1：违反义务悖论（Contrary-to-Duty Paradox）

考虑：

1. O(帮助邻居)

2. 如果不帮助邻居，则O(道歉)

3. 不帮助邻居

SDL推导出矛盾。

问题2：善良撒玛利亚人悖论

从"有义务帮助被抢劫的人"，SDL推导出"有义务存在被抢劫的人"。

解决方案：

我们使用SDL的扩展版本，增加：

  • 条件义务：O(φ|ψ)（在ψ条件下有义务φ）
  • 优先级关系：处理义务冲突

在本书中的应用：

  • 三大规范原则的形式化（第十章）
  • 禁忌红线的推导（第十章）
  • 规范决策的形式化（第二十章）

Coq中的道义逻辑：

```coq

( 道义算子 )

Parameter Obligation : Prop -> Prop.

Notation "'O' p" := (Obligation p) (at level 75).

Parameter Permission : Prop -> Prop.

Notation "'P' p" := (Permission p) (at level 75).

( 基本关系 )

Axiom permission_def : forall p, P p <-> ~ O (~ p).

Definition Forbidden (p : Prop) : Prop := O (~ p).

Notation "'F' p" := (Forbidden p) (at level 75).

( SDL公理 )

Axiom D1 : forall p q, O (p -> q) -> (O p -> O q).

Axiom D2 : ~ O False.

Axiom D3 : forall p, O p -> P p.

( 条件义务（扩展） )

Parameter ConditionalObligation : Prop -> Prop -> Prop.

Notation "'O' ( p | q )" := (ConditionalObligation p q) (at level 75).

§2.1.4 时态逻辑（Temporal Logic）

为什么需要时态逻辑？

时态逻辑用于表述时间关系和过程，这对于：

  • 过程本体论的形式化
  • 跨代决策的表述
  • 可逆性的时间维度

基本算子：

线性时态逻辑（LTL）：

  • G(φ)：总是φ（Globally）
  • F(φ)：最终φ（Finally）
  • X(φ)：下一时刻φ（neXt）
  • φ U ψ：φ直到ψ（Until）

关系：

F(φ) ≝ true U φ

G(φ) ≝ ¬F(¬φ)

语义：

时间结构：

T = (N, <)（自然数上的小于关系）

路径：

π = s₀, s₁, s₂, ...（状态序列）

满足关系：

```

π, i ⊨ X(φ) iff π, i+1 ⊨ φ

π, i ⊨ F(φ) iff exists j ≥ i such that π, j ⊨ φ

π, i ⊨ G(φ) iff for all j ≥ i, π, j ⊨ φ

π, i ⊨ φ U ψ iff exists j ≥ i such that π, j ⊨ ψ and

for all i ≤ k < j, π, k ⊨ φ

```

重要性质：

G(φ → ψ) → (G(φ) → G(ψ)) [分配律]

G(φ) → φ ∧ X(G(φ)) [展开律]

F(φ) ↔ φ ∨ X(F(φ)) [展开律]

在本书中的应用：

  • 过程本体论的形式化（第五章）
  • 跨代决策的时态结构（第十八章）
  • 可逆性的时间维度（第二十三章）

Coq中的时态逻辑：

```coq

( 时间点 )

Definition Time := nat.

( 状态 )

Parameter State : Type.

Parameter path : Time -> State.

( 时态算子 )

Definition Next (P : State -> Prop) (t : Time) : Prop :=

P (path (S t)).

Definition Eventually (P : State -> Prop) (t : Time) : Prop :=

exists t' : Time, t' >= t /\ P (path t').

Definition Always (P : State -> Prop) (t : Time) : Prop :=

forall t' : Time, t' >= t -> P (path t').

Definition Until (P Q : State -> Prop) (t : Time) : Prop :=

exists t' : Time, t' >= t /\ Q (path t') /\

forall t'' : Time, t <= t'' < t' -> P (path t'').

```

§2.1.5 认知逻辑（Epistemic Logic）

为什么需要认知逻辑？

认知逻辑用于表述知识和信念，这对于：

  • 新认知观的形式化
  • 知识社会性的表述
  • 多主体决策

基本算子：

单主体：

  • K_i(φ)：主体i知道φ
  • B_i(φ)：主体i相信φ

多主体：

  • E(φ)：每个人都知道φ（Everyone knows）
  • C(φ)：共同知识φ（Common knowledge）

公理（系统S5）：

K1: K_i(φ → ψ) → (K_i(φ) → K_i(ψ)) [分配律]

K2: K_i(φ) → φ [真实性]

K3: K_i(φ) → K_i(K_i(φ)) [正内省]

K4: ¬K_i(φ) → K_i(¬K_i(φ)) [负内省]

共同知识的定义：

```

E(φ) ≝ K₁(φ) ∧ K₂(φ) ∧ ... ∧ Kₙ(φ)

E²(φ) ≝ E(E(φ))

...

C(φ) ≝ E(φ) ∧ E²(φ) ∧ E³(φ) ∧ ...

```

可能世界语义：

认知模型：

M = (W, {R_i}_{i∈Agents}, V)

  • W：可能世界
  • R_i：主体i的认知可达关系（w R_i w' 表示在w中，i认为w'是可能的）
  • V：赋值函数

满足关系：

M, w ⊨ K_i(φ) iff for all w' such that w R_i w', M, w' ⊨ φ

```

在本书中的应用：

  • 知识社会性的形式化（第八章）
  • 认识共同体的表述（第十三章）
  • 多主体决策（第十七章）

Coq中的认知逻辑：

```coq

( 主体 )

Parameter Agent : Type.

( 认知算子 )

Parameter Knows : Agent -> Prop -> Prop.

Notation "'K[' i ']' p" := (Knows i p) (at level 75).

( S5公理 )

Axiom K_dist : forall (i : Agent) (p q : Prop),

K[i](p -> q) -> (K[i]p -> K[i]q).

Axiom K_truth : forall (i : Agent) (p : Prop),

K[i]p -> p.

Axiom K_pos_intro : forall (i : Agent) (p : Prop),

K[i]p -> K[i](K[i]p).

Axiom K_neg_intro : forall (i : Agent) (p : Prop),

~ K[i]p -> K[i](~ K[i]p).

( 共同知识 )

Parameter CommonKnowledge : Prop -> Prop.

Notation "'C' p" := (CommonKnowledge p) (at level 75).

( 共同知识的不动点性质 )

Axiom common_knowledge_fixpoint : forall p,

C p <-> (forall i : Agent, K[i]p) /\ C(C p).

```

§2.2 数学工具

§2.2.1 范畴论（Category Theory）

为什么需要范畴论？

范畴论是"数学的数学"，它提供：

  • 统一的语言表述数学结构
  • 关系优先的视角（态射优先于对象）
  • 丰富的工具（函子、自然变换、极限）

这使得范畴论天然适合关系本体论的形式化。

基本概念：

定义2.1（范畴）：

范畴C包含：

  • Obj(C)：对象的集合
  • 对于任意对象A, B，Hom(A, B)：从A到B的态射集合
  • 复合运算：∘: Hom(B, C) × Hom(A, B) → Hom(A, C)
  • 恒等态射：id_A ∈ Hom(A, A)

满足：

1. 结合律：(h ∘ g) ∘ f = h ∘ (g ∘ f)

2. 单位律：id_B ∘ f = f = f ∘ id_A（对于f: A → B）

示例：

范畴Set：

  • 对象：集合
  • 态射：函数
  • 复合：函数复合
  • 恒等：恒等函数

范畴Grp：

  • 对象：群
  • 态射：群同态
  • 复合：同态复合
  • 恒等：恒等同态

定义2.2（函子）：

函子F: C → D是范畴之间的映射：

  • 对象映射：F: Obj(C) → Obj(D)
  • 态射映射：F: Hom_C(A, B) → Hom_D(F(A), F(B))

满足：

1. F(id_A) = id_{F(A)}

2. F(g ∘ f) = F(g) ∘ F(f)

定义2.3（自然变换）：

自然变换η: F ⇒ G（F, G: C → D是函子）是态射族：

  • η_A: F(A) → G(A)（对于每个对象A ∈ C）

满足自然性条件：

  • 对于任意f: A → B，G(f) ∘ η_A = η_B ∘ F(f)

图示：

F(A) --η_A--> G(A)

| |

F(f) G(f)

| |

v v

F(B) --η_B--> G(B)

定义2.4（极限）：

对象A的极限是满足泛性质的对象：

  • 存在态射π_i: A → A_i（投影）
  • 对于任意对象B和态射f_i: B → A_i，存在唯一的u: B → A使得f_i = π_i ∘ u

特殊极限：

  • 积（Product）：A × B
  • 拉回（Pullback）
  • 等化子（Equalizer）

在本书中的应用：

  • 关系本体论的形式化（第四章）
  • 关系不可还原性定理（定理4.7）

Coq中的范畴论：

```coq

( 范畴的定义 )

Class Category := {

Obj : Type;

Hom : Obj -> Obj -> Type;

compose : forall {A B C}, Hom B C -> Hom A B -> Hom A C;

id : forall {A}, Hom A A;

( 公理 )

compose_assoc : forall {A B C D} (f : Hom A B) (g : Hom B C) (h : Hom C D),

compose h (compose g f) = compose (compose h g) f;

compose_id_left : forall {A B} (f : Hom A B),

compose id f = f;

compose_id_right : forall {A B} (f : Hom A B),

compose f id = f

}.

Notation "g ∘ f" := (compose g f) (at level 40, left associativity).

( 函子的定义 )

Class Functor (C D : Category) := {

F_obj : Obj -> Obj;

F_mor : forall {A B}, Hom A B -> Hom (F_obj A) (F_obj B);

( 公理 )

F_id : forall {A}, F_mor (@id C A) = @id D (F_obj A);

F_compose : forall {A B C} (f : Hom A B) (g : Hom B C),

F_mor (g ∘ f) = F_mor g ∘ F_mor f

}.

```

§2.2.2 拓扑学（Topology）

为什么需要拓扑学？

拓扑学研究空间的性质，特别是：

  • 连续性
  • 连通性
  • 紧致性
  • 维度

这些概念对于形式化"可能性空间"和"可逆性"至关重要。

基本概念：

定义2.5（拓扑空间）：

拓扑空间(X, τ)包含：

  • X：集合（点的集合）
  • τ ⊆ ℘(X)：开集族

满足：

1. ∅, X ∈ τ

2. 任意并：{U_i}_{i∈I} ⊆ τ ⇒ ⋃_{i∈I} U_i ∈ τ

3. 有限交：U, V ∈ τ ⇒ U ∩ V ∈ τ

示例：

欧几里得拓扑：

  • X = ℝⁿ
  • τ = {U ⊆ ℝⁿ | U是开球的并}

离散拓扑：

  • τ = ℘(X)（所有子集都是开集）

平凡拓扑：

  • τ = {∅, X}

定义2.6（连续映射）：

映射f: X → Y是连续的，如果：

  • 对于任意开集V ⊆ Y，f⁻¹(V)是X中的开集

定义2.7（同胚）：

映射f: X → Y是同胚，如果：

  • f是双射
  • f和f⁻¹都是连续的

同胚的空间在拓扑意义上是"相同的"。

定义2.8（维度）：

拓扑空间的维度有多种定义：

覆盖维度（Lebesgue covering dimension）：

```

dim(X) = min{n | 任意开覆盖都有细化，其中每点最多属于n+1个开集}

```

归纳维度：

```

dim(∅) = -1

dim(X) ≤ n iff 对于任意点x和开邻域U，存在开邻域V使得x ∈ V ⊆ U且dim(∂V) ≤ n-1

```

性质：

  • dim(ℝⁿ) = n
  • 同胚保持维度

在本书中的应用：

  • 可能性空间的拓扑结构（第二十三章）
  • RFD的拓扑不变性（定理23.5）
  • 可逆性的维度刻画

Coq中的拓扑学：

```coq

( 拓扑空间的定义 )

Class TopologicalSpace (X : Type) := {

Open : (X -> Prop) -> Prop;

( 公理 )

open_empty : Open (fun _ => False);

open_full : Open (fun _ => True);

open_union : forall (F : (X -> Prop) -> Prop),

(forall U, F U -> Open U) -> Open (fun x => exists U, F U /\ U x);

open_intersection : forall (U V : X -> Prop),

Open U -> Open V -> Open (fun x => U x /\ V x)

}.

( 连续映射 )

Definition continuous {X Y : Type}

`{TopologicalSpace X} `{TopologicalSpace Y}

(f : X -> Y) : Prop :=

forall V : Y -> Prop, Open V -> Open (fun x => V (f x)).

( 同胚 )

Definition homeomorphism {X Y : Type}

`{TopologicalSpace X} `{TopologicalSpace Y}

(f : X -> Y) : Prop :=

continuous f /\

(exists g : Y -> X, continuous g /\

(forall x, g (f x) = x) /\ (forall y, f (g y) = y)).

```

§2.2.3 测量论（Measurement Theory）

为什么需要测量论？

测量论提供严格的测量基础，确保：

  • 测量是有意义的（表示定理）
  • 测量是唯一的（唯一性定理）
  • 测量可以比较（量表类型）

这对于指标设计至关重要。

基本概念：

定义2.9（经验关系系统）：

经验关系系统A = (X, {R_i}_{i∈I})包含：

  • X：对象集合
  • {R_i}：关系族（如≿, ∼, ⊕）

示例：

  • (X, ≿)：偏好关系
  • (X, ≿, ⊕)：可加结构

定义2.10（数值关系系统）：

数值关系系统N = (ℝ, {S_i}_{i∈I})包含：

  • ℝ：实数集
  • {S_i}：数值关系（如≥, =, +）

定义2.11（表示）：

表示是同态φ: A → N：

  • 保持关系结构

示例：

```

如果x ≿ y，则φ(x) ≥ φ(y)

如果x ⊕ y ∼ z，则φ(x) + φ(y) = φ(z)

```

定理2.4（表示定理）：

在一定条件下，存在表示φ: A → N。

定义2.12（唯一性）：

表示φ是唯一的（在变换类T下），如果：

  • 对于任意表示ψ，存在t ∈ T使得ψ = t ∘ φ

量表类型：

量表类型唯一性允许变换示例
名义量表一一对应任意一一对应分类
序数量表单调变换严格递增函数偏好排序
区间量表正线性变换φ' = aφ + b (a > 0)温度（摄氏/华氏）
比率量表相似变换φ' = aφ (a > 0)长度、质量
绝对量表恒等变换φ' = φ计数

在本书中的应用：

  • UCS的测量论基础（第二十二章）
  • 表示定理和唯一性定理（定理22.3）
  • 指标的量表类型分析

Coq中的测量论：

```coq

( 经验关系系统 )

Class EmpiricalRelationalSystem (X : Type) := {

preference : X -> X -> Prop;

( 可以添加更多关系 )

}.

Notation "x ≿ y" := (preference x y) (at level 70).

( 表示 )

Definition representation {X : Type} `{EmpiricalRelationalSystem X}

(φ : X -> R) : Prop :=

forall x y, x ≿ y <-> (φ x >= φ y)%R.

( 唯一性（区间量表） )

Definition interval_scale_uniqueness {X : Type}

`{EmpiricalRelationalSystem X}

(φ ψ : X -> R) : Prop :=

representation φ -> representation ψ ->

exists (a b : R), (a > 0)%R /\ forall x, (ψ x = a φ x + b)%R.

( 表示定理（需要额外公理） )

Axiom representation_theorem : forall {X : Type}

`{EmpiricalRelationalSystem X},

( 假设满足某些条件（如完备性、传递性等） )

§2.2.4 信息论（Information Theory）

为什么需要信息论？

信息论提供：

  • 熵的精确定义
  • 信息量的度量
  • 负熵与信息的联系

这对于形式化"负熵责任原则"至关重要。

基本概念：

定义2.13（熵）：

离散随机变量X的熵：

```

H(X) = -∑_{x∈X} p(x) log p(x)

```

性质：

  • H(X) ≥ 0
  • H(X) = 0 iff X是确定的
  • H(X)最大当X是均匀分布

定义2.14（条件熵）：

给定Y时X的条件熵：

```

H(X|Y) = ∑_{y∈Y} p(y) H(X|Y=y)

= -∑_{x,y} p(x,y) log p(x|y)

```

定义2.15（互信息）：

X和Y的互信息：

```

I(X;Y) = H(X) - H(X|Y)

= H(Y) - H(Y|X)

= H(X) + H(Y) - H(X,Y)

```

解释： I(X;Y)度量X和Y共享的信息量。

定义2.16（相对熵/KL散度）：

分布P相对于Q的相对熵：

```

D(P||Q) = ∑_x p(x) log(p(x)/q(x))

```

性质：

  • D(P||Q) ≥ 0
  • D(P||Q) = 0 iff P = Q

连续情况：

连续随机变量X的微分熵：

```

h(X) = -∫ f(x) log f(x) dx

```

注意： 微分熵可以是负数。

在本书中的应用：

  • 负熵的形式化（第九章）
  • 负熵与信息的等价性（定理9.8）
  • CRV的信息论表述（第二十三章）

Coq中的信息论：

§2.3 证明技术

§2.3.1 Coq基础

Coq简介：

Coq是基于Calculus of Inductive Constructions (CIC)的证明助手。

核心特性：

  • 依赖类型系统
  • 归纳类型
  • 策略语言（tactics）
  • 提取到OCaml/Haskell

基本工作流程：

```coq

( 1. 定义类型和函数 )

Inductive nat : Type :=

| O : nat

| S : nat -> nat.

Fixpoint plus (n m : nat) : nat :=

match n with

| O => m

| S n' => S (plus n' m)

end.

( 2. 陈述定理 )

Theorem plus_O_n : forall n : nat, plus O n = n.

( 3. 证明 )

Proof.

intros n.

simpl.

reflexivity.

Qed.

( 4. 使用定理 )

Theorem plus_n_O : forall n : nat, plus n O = n.

Proof.

induction n as [| n' IHn'].

  • ( n = O )

apply plus_O_n.

  • ( n = S n' )

simpl.

rewrite IHn'.

reflexivity.

Qed.

```

常用策略：

策略作用示例
intros引入假设intros x y H
apply应用定理apply H
rewrite重写rewrite H
reflexivity自反性reflexivity
simpl化简simpl
induction归纳induction n
destruct分情况destruct H
exists存在引入exists x

示例：归纳证明

```coq

( 定理：加法结合律 )

Theorem plus_assoc : forall n m p : nat,

plus (plus n m) p = plus n (plus m p).

Proof.

intros n m p.

induction n as [| n' IHn'].

  • ( n = O )

simpl.

reflexivity.

  • ( n = S n' )

simpl.

rewrite IHn'.

reflexivity.

Qed.

```

在本书中的使用：

  • 约60%的定理使用Coq证明
  • 核心定理都有Coq验证
  • 代码仓库：formal-systems/coq/

§2.3.2 Isabelle/HOL基础

Isabelle简介：

Isabelle是通用的证明助手，

Isabelle/HOL是其最流行的实例（基于高阶逻辑）。

核心特性：

  • 高阶逻辑（HOL）
  • 强大的自动化工具（Sledgehammer）
  • 丰富的库（Archive of Formal Proofs）
  • 结构化证明语言（Isar）

基本工作流程：

```isabelle

theory Example

imports Main

begin

( 1. 定义 )

fun plus :: "nat ⇒ nat ⇒ nat" where

"plus 0 m = m" |

"plus (Suc n) m = Suc (plus n m)"

( 2. 陈述定理 )

theorem plus_O_n: "plus 0 n = n"

( 3. 证明（自动） )

by simp

( 4. 归纳证明 )

theorem plus_n_O: "plus n 0 = n"

proof (induction n)

case 0

show ?case by simp

next

case (Suc n)

then show ?case by simp

qed

( 5. 使用Sledgehammer )

theorem plus_assoc: "plus (plus n m) p = plus n (plus m p)"

by (induction n) auto

end

```

Isar结构化证明：

```isabelle

theorem plus_comm: "plus n m = plus m n"

proof (induction n)

case 0

have "plus 0 m = m" by simp

also have "... = plus m 0" by (simp add: plus_n_O)

finally show ?case .

next

case (Suc n)

have "plus (Suc n) m = Suc (plus n m)" by simp

also have "... = Suc (plus m n)" using Suc.IH by simp

also have "... = plus m (Suc n)" by simp

finally show ?case .

qed

```

Sledgehammer：

Sledgehammer是Isabelle的自动证明工具，它：

  • 调用外部ATP（自动定理证明器）
  • 找到相关引理
  • 生成Isabelle证明

```isabelle

theorem example: "P ∧ Q ⟹ Q ∧ P"

by (sledgehammer)

( Sledgehammer找到证明：by auto )

```

在本书中的使用：

  • 约30%的定理使用Isabelle证明
  • 特别适合复杂的数学证明
  • 代码仓库：formal-systems/isabelle/

§2.3.3 Lean 4基础

Lean简介：

Lean是现代化的证明助手，由微软研究院开发。

核心特性：

  • 依赖类型理论
  • 强大的类型类系统
  • 优秀的性能
  • 活跃的社区（mathlib）

基本工作流程：

```lean

-- 1. 定义

inductive Nat where

| zero : Nat

| succ : Nat → Nat

def plus : Nat → Nat → Nat

| Nat.zero, m => m

| Nat.succ n, m => Nat.succ (plus n m)

-- 2. 陈述定理

theorem plus_zero_n (n : Nat) : plus Nat.zero n = n := by

rfl

-- 3. 归纳证明

theorem plus_n_zero (n : Nat) : plus n Nat.zero = n := by

induction n with

| zero => rfl

| succ n ih =>

simp [plus]

rw [ih]

-- 4. 使用策略

theorem plus_assoc (n m p : Nat) :

plus (plus n m) p = plus n (plus m p) := by

induction n with

| zero => rfl

| succ n ih =>

simp [plus]

rw [ih]

```

类型类：

```lean

-- 定义类型类

class Add (α : Type) where

add : α → α → α

-- 实例

instance : Add Nat where

add := plus

-- 使用

def double {α : Type} [Add α] (x : α) : α :=

Add.add x x

eval double 5 -- 10

```

策略模式：

```lean

theorem example (p q : Prop) : p ∧ q → q ∧ p := by

intro h

cases h with

| intro hp hq =>

constructor

  • exact hq
  • exact hp

```

在本书中的使用：

  • 约10%的定理使用Lean证明
  • 主要用于探索新型定理
  • 代码仓库：formal-systems/lean/

§2.3.4 证明策略与技巧

策略1：归纳法

适用场景： 证明关于归纳类型的性质

模式：

```

要证明：∀n: Nat, P(n)

基础情况：证明P(0)

归纳步骤：假设P(n)，证明P(n+1)

```

示例（Coq）：

```coq

Theorem plus_comm : forall n m : nat,

plus n m = plus m n.

Proof.

intros n m.

induction n as [| n' IHn'].

  • ( n = 0 )

simpl.

rewrite plus_n_O.

reflexivity.

  • ( n = S n' )

simpl.

rewrite IHn'.

rewrite plus_n_Sm.

reflexivity.

Qed.

```

策略2：分情况讨论

适用场景： 证明涉及多种情况的命题

模式：

```

要证明：P(x)

情况1：假设C1(x)，证明P(x)

情况2：假设C2(x)，证明P(x)

...

```

示例（Isabelle）：

```isabelle

theorem example: "P x"

proof (cases x)

case Case1

then show ?thesis sorry

next

case Case2

then show ?thesis sorry

qed

```

策略3：反证法

适用场景： 直接证明困难时

模式：

```

要证明：P

假设：¬P

推导出矛盾

结论：P

```

示例（Lean）：

```lean

theorem example (p : Prop) : ¬¬p → p := by

intro h

by_contra hnp

exact h hnp

```

策略4：构造性证明

适用场景： 证明存在性命题

模式：

```

要证明：∃x, P(x)

构造：找到具体的x₀

验证：证明P(x₀)

```

示例（Coq）：

```coq

Theorem exists_example : exists n : nat, n + 5 = 10.

Proof.

exists 5.

reflexivity.

Qed.

```

策略5：使用引理

适用场景： 复杂证明需要分解

模式：

```

主定理：P

引理1：Q

引理2：Q → R

引理3：R → P

证明：由引理1、2、3得P

```

示例（Coq）：

```coq

Lemma helper : forall n, n + 0 = n.

Proof. ( ... ) Qed.

Theorem main : forall n m, n + m + 0 = n + m.

Proof.

intros n m.

rewrite helper.

reflexivity.

Qed.

```

策略6：自动化

适用场景： 简单或标准的证明

工具：

  • Coq: `auto`, `omega`, `lia`
  • Isabelle: `auto`, `simp`, `sledgehammer`
  • Lean: `simp`, `omega`, `decide`

示例（Isabelle）：

```isabelle

theorem "x + y = y + x"

by (sledgehammer)

( 自动找到：by simp )

```

策略7：重写

适用场景： 使用等式变换

模式：

```

已知：x = y

目标：P(x)

重写：P(x) = P(y)

证明：P(y)

```

示例（Coq）：

```coq

Theorem example : forall n m,

n = m -> n + 1 = m + 1.

Proof.

intros n m H.

rewrite H.

reflexivity.

Qed.

```
