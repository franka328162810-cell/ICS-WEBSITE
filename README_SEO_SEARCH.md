## 💡 使用示例

### 例1：搜索"AI治理"
1. 在搜索框输入：`AI治理`
2. 点击"搜索"或按 Enter
3. 显示所有包含 AI 治理的文章

### 例2：只看"太空治理"文章
1. 点击"太空治理"按钮
2. 自动筛选显示太空治理文章

### 例3：在"伦理学"中搜索"生命"
1. 点击"伦理学"按钮
2. 输入：`生命`
3. 显示伦理学分类中包含"生命"的文章
